# A23.l3 — K4 `natural_key` v2 como contrato E2 (B3/B4)

Promove a chave natural K4 a campo de contrato do artefato E2, conforme [[ADR-278]]:

- **B3** — hash versionado: `_hash_v1` congelado (contrato com hashes no DB) + `_hash_v2`
  que ingere **cents int via `Decimal`** (ADR-090, sem float-drift) e discrimina
  `moeda` + `direction` (entrada R$100 ≠ saída R$100 ≠ USD100). `HashInputs` +
  `compute_natural_key`; `derive_direction` espelha `_normalize_tipo` (fatura inverte sinal).
- **B4 passo 1** — `stamp_natural_key` no write-path comum de E2 (determinístico + LLM);
  faturas sem titular → `natural_key=null` (classe-c); schema E2 aceita `natural_key`/
  `direction` opcionais. F1 emite + mede, **não consome** → goldens verdes sem rebaseline (G1).

**Pendente:** passo 2 (nullable→obrigatório) gated por cobertura 100% + dívida **D6**
(`generate_transaction_hash`), cuja decisão é [[ADR-282]] (Proposto).
