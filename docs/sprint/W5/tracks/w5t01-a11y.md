## Briefing

Findings PD-007/014/015/021 levantam 4 lacunas WCAG 2.1 AA sobreviventes
pós report-a11y-finalize:

- **PD-007** — `<th>` sem `scope="col"` em tabelas do relatório (axe `serious`).
- **PD-014** — barras de progresso (IFHero, EquilibrioCerbasi, KpiCard) renderizam apenas `<div>` com largura inline; leitor de tela ignora valor (sem `role="progressbar"` nem `aria-valuenow/min/max`).
- **PD-015** — charts Recharts (S1 PatrimonioDoughnut, WaterfallIf, etc.) não declaram `aria-label` nem `<title>` no SVG — VoiceOver lê só "graphic, image".
- **PD-021** — `globals.css` não respeita `prefers-reduced-motion`; animações `transition-[width]`, `animate-indeterminate`, `transition-all duration-700` rodam sempre.

Lane fecha esses 4 com:
1. Patches mecânicos (`scope="col"`, `aria-label`, media query).
2. Primitivo `<ProgressBar/>` extraído + adoção em 3 call-sites.
3. axe-core gate sobe para `critical+serious+moderate` em a11y.@critical.spec.ts.

**Não cabe nesta lane:** Recharts → Chart.js (W5-T02), MonetaryValue (W5-T03), refactor de `<table>` para shadcn.

### 2. Primitivo `<ProgressBar/>` — novo arquivo

```tsx
// frontend/src/components/ui/ProgressBar.tsx
import type { CSSProperties, ReactNode } from "react";

export interface ProgressBarProps {
  readonly value: number;
  readonly max?: number;
  readonly label: string;
  readonly valueText?: string;
  readonly showValue?: boolean;
  readonly fillColor?: string;
  readonly trackColor?: string;
  readonly height?: number;
  readonly className?: string;
  readonly style?: CSSProperties;
  readonly children?: ReactNode;
}

export function ProgressBar({
  value,
  max = 100,
  label,
  valueText,
  showValue = false,
  fillColor = "linear-gradient(90deg, var(--brand-info), var(--brand-accent))",
  trackColor = "var(--surface-border)",
  height = 8,
  className,
  style,
  children,
}: ProgressBarProps) {
  const clamped = Math.max(0, Math.min(max, value));
  const pct = max === 0 ? 0 : (clamped / max) * 100;
  const computedValueText = valueText ?? `${pct.toFixed(0)}%`;

  return (
    <div className={className}>
      {children}
      <div
        role="progressbar"
        aria-label={label}
        aria-valuenow={clamped}
        aria-valuemin={0}
        aria-valuemax={max}
        aria-valuetext={computedValueText}
        style={{ width: "100%", height, background: trackColor, borderRadius: height / 2, overflow: "hidden", ...style }}
      >
        <div style={{ width: `${pct}%`, height: "100%", borderRadius: height / 2, background: fillColor, transition: "width 0.6s ease" }} />
      </div>
      {showValue && (
        <span className="ml-2 font-mono text-xs tabular-nums" aria-hidden="true">{computedValueText}</span>
      )}
    </div>
  );
}
```

1. **Contraste-AA dos tokens semânticos pós-W1-T01.** Subir gate `moderate` pode acender `color-contrast` em `--brand-warning`, `--alert`, `--neutral-financial`. 3. **`<ProgressBar/>` regression visual em IFHero.** Gradient atual `from-[var(--brand-info)] to-[var(--brand-accent)]` Tailwind vs `linear-gradient` inline. Pixel-perfeito mas baseline Playwright pode diferir <1px → reaprovar snapshot deliberadamente.
